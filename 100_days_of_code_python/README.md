# 100 Days of Code - Python

A structured collection of Python projects and challenges from the 100 Days of Code learning journey.

## Folder Structure

```
100_days_of_code_python/
├── day_41-50/          # Days 41-50 challenges (Web scraping, automation, etc.)
├── day_51-60/          # Days 51-60 challenges (Flask, Web development, etc.)
├── day_61-70/          # Days 61-70 challenges (Advanced web, APIs, etc.)
├── day_71-80/          # Days 71+ challenges (Data science, scripting, etc.)
└── miscellaneous/      # Other projects and exercises
```

### Day Ranges

- **day_41-50**: Web scraping with BeautifulSoup, Selenium, automation projects
- **day_51-60**: Flask web applications, Bootstrap, templating, database connections
- **day_61-70**: Advanced Flask, REST APIs, deployment basics
- **day_71-80**: Data exploration, visualization, automation scripting

### Miscellaneous

Contains various exercises and projects:
- CSS challenges (selectors, box model, colors)
- Turtle graphics projects
- Game development (snake, pong)
- Tkinter GUI applications
- File handling and data processing
- And more...

## Setup

1. Create a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```

2. Install dependencies (varies per project):
   - Check individual project directories for requirements.txt
   ```bash
   pip install -r [project_path]/requirements.txt
   ```

## Running Projects

Each project directory is self-contained. Navigate to the project folder and run:
```bash
python main.py
```

Or check the specific project's README for instructions.
